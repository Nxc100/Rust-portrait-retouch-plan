# 测试报告：奶油肌预设 vs 像素蛋糕导出（test/1V3A2861.jpg，第三轮）

日期：2026-09-24。命令：`retouch apply -i test/1V3A2861.jpg -o out/cream/ours_cream.jpg --preset cream`（JPEG 默认质量 98）。
对比脚本：`tools/compare_to_reference.py`（DIS 光流对齐，频段比在未重采样的输出上计算）与 `tools/texture_energy.py`（按局部能量分箱）。
第三轮与新样张 X04 的对比（`doc/test_report_x04.md` §6）一起进行；两张样张共用同一套参数，本报告只列海边样张的结果。
> 之后第四轮用 7 张新原片（14 张脸）重新标定了色调、瑕疵与形变参数（`doc/test_report_batch.md`），
> 本报告的数字是第三轮参数下的结果；第四轮参数在本样张上的回归对照见该报告 §3。
第二轮改动见附录 A，第一轮结果见附录 B。

## 1. 第三轮改动

| 发现 | 原因 | 改动 |
|---|---|---|
| **输出 JPEG 本身吃掉 4–7% 的最细纹理** | image 0.25 自带编码器在量化前做整数截断（`dct / 8`），低幅度系数系统性变小：原图直通重编码，q97 最细一档只剩 0.93–0.96，q100 也只有 0.93；之前所有纹理数字都带着这层损失 | 改用 jpeg-encoder 0.7（量化正确舍入、4:4:4、优化霍夫曼表），直通重编码的各带比 1.00–1.03。默认质量 95 → 98，与像素蛋糕导出的量化表一致（亮度表最大 5，约等于 IJG q98）。同时写回原图的 ICC 配置文件与 EXIF；不写 XMP，否则其中的 crs 冲印设置会被下游软件再应用一次 |
| 形变把皮肤颗粒插值掉 | 在分数像素位置，双线性插值会把相邻像素平均，颗粒幅度只剩 0.5–0.7；Catmull-Rom 仍损失约 15% | 保纹理重采样（`warp/apply.rs`）：基底（σ1 高斯）用双三次采样；细节层在平滑区用最近邻、在强边缘用双三次，两者按局部能量过渡。形变耗时 4.7 s → 0.28 s（只遍历各脸包围盒） |
| 像素蛋糕的中频衰减随局部能量变化，新郎的曲线在对数能量上缓慢上升 | 按能量分箱统计：平滑皮肤处中频只剩 0.60–0.70，纹理处约 0.95；新郎的保留比例从 E≈0.7 一直升到 E≈11，线性刻度的 smoothstep 拟合不了 | α_mid(E) 改为在 ln E 上做 smoothstep（女 1.2–3.5，男 0.7–11），高能量处也保留约 8% 的衰减（`KEEP_MAX`）。强度调整：中频上限 α 女 0.50 → 0.60、男 0.45 → 0.61；细颗粒 α 女 0.10 → 0.22、男 0.03 → 0.10 |
| 色度匀肤偏弱（换编码器后才看得出来） | a/b 中频比 0.86–0.89，像素蛋糕 0.75–0.79 | `chroma_smooth` 女 0.22 → 0.36，男 0.20 → 0.29，身体 0.25 → 0.35 |
| 大面积高光被"匀肤"加黄（X04 新娘 L 90+ b +1.3），同时亮部降黄不够 | 低频色度统一把所有颜色往皮肤均值拉，而高光本来就饱和度低（反射光），被拉向更黄更红；像素蛋糕在两张样张上都是皮肤越亮、降黄越多 | 统一改为向"色度 ~ L 的遮罩内加权回归线"压缩，只压缩偏离回归线的部分；新增 `yellow_bright`（L 50→85 渐增，女 / 男 −0.9），`yellow_highlight` −1.0 → −0.5 |
| 眼区更清晰 | 像素蛋糕眼区 L 标准差：新郎 +4%、新娘 +5% | 新增 `eye_contrast`：眼眶椭圆内做局部对比 `L += k·(L − G(L; 0.04·瞳距))`，女 0.30、男 0.25 |
| 侧脸的纹理尺度偏小 | 侧脸时瞳距按 cos(yaw) 缩短（X04 新郎 70.7 px，按头部大小折算应约 112 px） | 纹理 / 瑕疵的尺度改用 `FaceKeyPoints::scale_distance()` = max(瞳距, 鼻梁顶—下巴距离 / 2)；正脸结果不变 |
| 偶发 70–77 s 的卡顿 | ABPN 检测网络中出现非规格化浮点，CPU 走慢路径 | ORT 开启 `session.set_denormal_as_zero`，并在推理线程设置 FTZ/DAZ（`DenormalGuard`） |

## 7. 尚存差距与可调项

1. 发丝阴影的孤立末端偶尔被当作痣修复：把 `cream_female.body_heal.max_aspect` 降到 3、`min_fill` 提到 0.4 可以减少，
   代价是拉长的疤痕会漏检。
2. 像素蛋糕的手部和鼻侧毛孔更平：可以再提高 `body_low_smooth`（0.25）/ `body_smooth`（0.50）和女性的 `energy_hi`（3.5）。
3. AI 瑕疵模型只对人脸 ROI 运行；身体上的大瑕疵由经典的 `heal` 处理。
4. 性别分档依赖 insightface genderage（非商用）；没有该模型时用 `cream_unknown` / `reshape.unknown` 中间档。

# 预设的实现：「奶油肌」与「婚纱-深色内景」

两个内置预设都对标像素蛋糕的同名预设。本文沉淀它们的实现：一条流水线、哪些是共用的算子、哪些是各自的参数与开关、
每个功能为什么这样做、常数从哪里来。加新预设的步骤见 [adding_a_preset.md](adding_a_preset.md)。

逐项的逆向分析与测试数据：
- 奶油肌：doc/analysis/cream_skin.md、doc/test_report_cream.md、test_report_batch.md、test_report_body_tone.md、
  test_report_neck.md、test_report_shadow_blotches.md；
- 婚纱-深色内景：doc/analysis/wedding_dark_interior.md、doc/test_report_wedding_dark_interior.md；
- 两者并排的最终对照：doc/test_report_final.md（对比图在 out/最终对照组/对比图/）。

## 1. 预设是什么

预设是一份数据：`Preset`（src/preset.rs）→ `Preset::to_params()` → `RetouchParams`（src/pipeline.rs）→ 流水线。
两个预设走同一条流水线（`SmoothMode::Cream`），区别只在参数值与开关。代码里「婚纱-深色内景」写成
"奶油肌之上改一部分"（`..Self::cream_skin()`），不另写流程。

| 位置 | 内容 |
|---|---|
| `src/preset.rs` | `Preset` 结构、内置预设函数（`cream_skin()`、`wedding_dark_interior()` 及各性别参数函数）、`builtin_names()`、`load_named()` 别名 |
| `presets/*.json` | 内置预设的导出（`retouch preset --name <名> -o ...`），可编辑后 `--preset <文件>` 加载 |
| `src/skin/cream.rs` | `CreamParams`（每个性别一套：磨皮、匀肤、色调、立体、身体、牙齿、归属……）与奶油肌修图 `cream_skin` |
| `src/color/grade.rs` | 预设调色（只有深色内景用）；`GradeParams` 在 `Preset.grade` 里，`None` 即不调色 |
| `luts/wedding_dark_interior.cube` | 深色内景的全局 LUT（`include_str!` 编译进程序，预设里写 `builtin:wedding_dark_interior`） |

`CreamParams` 有 `#[serde(default)]`：预设 JSON 缺字段时取 `Default`，所以给 `CreamParams` 加新字段不会让旧预设文件
失效——新功能一律默认关闭，只在需要的预设里打开，旧预设的输出逐字节不变。

## 2. 流水线（奶油肌模式，按执行顺序）

| # | 步骤 | 代码 | 两个预设 |
|---|---|---|---|
| 1 | 人脸检测、106 点关键点、人脸解析（19 类）、性别年龄 | `face/`，`Engine::detect_faces` | 共用 |
| 2 | 人像 alpha（MODNet）、语义皮肤概率（skin_seg）；需要时才算（`engine.rs::needs_matte`） | `face/matting.rs`、`face/skinseg.rs` | 共用 |
| 3 | AI 瑕疵祛除（ABPN 补丁，只含改动像素） | `skin/ai_blemish.rs`，`pipeline::cream_base` | 共用 |
| 4 | **预设调色**：自适应软黑点 → 全局 3D LUT → 人物主体 LUT（按人像 alpha） | `color/grade.rs`，`pipeline::apply_grade` | 仅深色内景 |
| 5 | 皮肤遮罩：每张脸的解析皮肤（去掉眼眉嘴等）、身体（人像 ∧ 肤色规则 ∧ 语义皮肤，再按颜色连续性修正）、脖子 | `skin/masks.rs::build_skin_masks`、`skin/continuity.rs` | 共用 |
| 6 | 奶油肌修图 `cream_skin`：逐张脸（6a–6h），再身体（6i），再脖子（6j），最后按遮罩混合回去 | `skin/cream.rs` | 共用，参数不同 |
| 6a | 脸部遮罩按人归属：去掉落在别人脸轮廓内的部分（`FaceOutlines`） | `cream_skin` | 两者都开（算子默认关） |
| 6b | 大尺度瑕疵修复（疤痕、大痣：环核检测 + 调和插值 + 纹理移植） | `skin/heal.rs` | 共用 |
| 6c | 小瑕疵祛除（紧凑斑点检测 + 归一化卷积填充） | `skin/blemish.rs` | 共用 |
| 6d | 亮度三频段磨皮：细颗粒（< fine_sigma）、中频（fine_sigma–mid_sigma，按局部纹理能量自适应）、低频（mid_sigma–detail_radius） | `process_region` 第 3 步 | 共用，强度不同 |
| 6e | 色度匀肤、低频色度按"随亮度变化的皮肤色度"统一 | 第 4 步 | 共用 |
| 6f | 脸部色调：中间调钟形提亮、最高光压制、低频红度 / 黄度按比例拉向目标色、随亮度的黄度偏移 | 第 5 步 | 共用，常数差很多 |
| 6g | **立体**：脸内 0.06–0.25 瞳距的明暗结构按比例加强（`stereo`） | 第 5b 步 | 仅深色内景（算子默认 0） |
| 6h | 眼部清晰（眼眶椭圆内的局部对比） | 第 6 步 | 共用 |
| 6i | 身体：同样三频段 + 匀肤；身体色调（提亮平台、降红、降黄按比例拉向目标，按到各脸距离混合各人参数）；**色调外溢**到语义遮罩漏掉的相邻皮肤 | `process_region`（身体分支）、`skin/spill.rs` | 外溢仅深色内景 |
| 6j | 颈纹淡化（保边平滑 + 细线填平；脖子按人归属） | `skin/neck.rs` | 共用 |
| 7 | 牙齿美白（口腔解析 × 自适应颜色门限，权重在调色后、修图前的图上算） | `skin/teeth.rs`，`pipeline::cream_teeth` | 两者都开，强度不同 |
| 8 | 形变：瘦脸、小脸、缩下巴、瘦鼻、放大眼（美狐式，按偏转角减弱） | `warp/` | 共用，强度不同 |
| 9 | 输出：jpeg-encoder 标准霍夫曼表 q98，保留元数据 | `photo.rs` | 共用 |

顺序上的两个关键决定：
- **先调色、后修图**：像素蛋糕的肤色统一作用在调色后的颜色上（深色内景整体压暗，皮肤仍被拉回目标色）；所以深色内景的
  肤色常数是在"只调色"的图上拟合的。其余磨皮模式（非奶油肌）的预计算取自原图，只能在磨皮之后调色。
- **形变最后做**：所有颜色处理都在原图几何上（遮罩、关键点都是原图坐标）；评估时要把输出光流对齐回原图几何。

## 4. 各功能的实现要点

### 4.1 预设调色（`color/grade.rs`，深色内景）
- 像素蛋糕这组"AI 风格"在同一张照片内是干净的逐像素颜色映射，但**各张之间不是同一张 LUT**：没有真正暗部的朦胧 / 高调
  画面被压得更暗。自适应软黑点 `b = 0.6·max(0, P2(min RGB) − 0.02)`（P2 为整图 min(R,G,B) 的 2% 分位）解释了大部分差异。
- 软黑点 `x' = (x − b·s(x))/(1 − b)`，`s = smoothstep(0, 2b, x)`：亮部同硬黑点，暗部不截断（硬黑点把头发压死）；
  只作用在保边底图上、细节原样加回（逐像素拉伸会把脸上纹理放大 1/(1 − b) 倍）。
- 全局 LUT 17³，由 `tools/grade_fit.py` 在背景像素上带平滑正则拟合；更大的 LUT 会记住每张照片自己的颜色、泛化更差。
- 人物主体：人像 alpha 内再做一次亮度曲线与色度增益（烘成第二张 LUT 按 alpha 混合）。`subject_weights` 去掉 alpha 里与人脸
  不相连的小块（背景墙灯饰被当成人）。
- 留一误差（其余照片拟合、这一张评估）：背景 3.65、主体 3.30 ΔE；在 7 张原片上整图中位 1.61（不处理 14.4）。

### 4.2 脸部色调（`cream.rs` 第 5 步）
模型（`tools/skin_tone_fit.py` 拟合，与代码逐项对应）：

    dL = lift·exp(−((L − 62)/26)²) − hl·t_hl + lift_per_b·b
    da = −pull_a·(a − target_a)
    db = −pull_b·(b − target_b) + y_br·t_br + y_hl·t_hl + y_sh·t_sh

a、b 用低频（σ 0.03 瞳距）色度：偏黄偏红的皮肤降得多，白净的几乎不动。深色内景的常数在"只调色"的图上拟合。
比例模型是跨脸的折中：像素蛋糕的"AI 肤色统一"逐脸自适应，逐脸残差 ±1～3 属于模型上限。

### 4.3 磨皮与立体（第 3、5b 步）
- 三频段：`fine = L − G(fine_sigma)`、`mid = G(fine_sigma) − G(mid_sigma)`（毛孔、斑驳、细纹，衰减按局部中频能量
  自适应——纹理 / 五官边缘处几乎不动）、`low = G(mid_sigma) − 保边底图`；`L' = L − α_fine·fine − α_mid(E)·mid − α_low·low`。
- 校准用**皮肤亮度各带通的中位幅度比**（`tools/skin_bands.py`），不用 RMS：像素蛋糕的清晰度 / 对比度放大少数强边缘，
  RMS 被它们主导，会让人以为纹理没减少、从而磨得太轻。
- 立体：`L += stereo·(G_m(L, 0.06·ed) − G_m(L, 0.25·ed))·mask`，`G_m` 为脸部遮罩内归一化低通（眼眉嘴、头发、背景不参与
  取样）。按像素亮度的提亮、压高光会把脸的明暗压平，像素蛋糕的"中性灰立体"反而加强它；用 `tools/band_gain.py`
  的大尺度增益 α 校准。下限取 0.06：0.03 会把斑驳那一档也抬起来。

### 4.4 身体色调与外溢（`cream.rs` 身体分支、`skin/spill.rs`）
- 身体提亮是低频亮度的平台函数（阴影到中间调提一样多、高光渐弱），降黄按比例拉向目标；身体像素按到各张脸中心的距离
  （以脸尺度为单位）软分配给各人（`owner_weight`，软度 0.5），混合各人的参数。常数由 `tools/body_tone_fit.py` 拟合。
- 外溢：语义皮肤模型会漏掉皮肤（红裙映红的胸口、高光）。遮罩外、人像内、离脸远、离已接受皮肤 0.3 瞳距以内且低频颜色相近
  的像素按相似度并入身体色调：比参考更红但是肤色色相（≥ 35°）时红度差折半（映红的皮肤），粉色的花与扇骨（色相
  15°～18°）不折；确认的外溢皮肤再加入参考色细化两轮。只补色调，磨皮与祛瑕疵仍只在遮罩内。

### 4.5 牙齿美白（`skin/teeth.rs`）
人脸解析的口腔（`CLS_MOUTH`）内：亮度门限 L 35→50 × 相对红度门限（参考红度 = 口腔最亮 25% 像素红度的中位数，门限
+8→+16：暖色内景、唇色映到牙齿上也不漏）；红度、黄度拉向 a 10、b 10，亮度向 100 拉 18%；牙齿权重羽化 ×2 覆盖牙龈线
（嘴唇更红、不动）。门限在调色后、修图前的颜色上算，`Engine::teeth_weights` 与 `--debug-dir` 的 `teeth.png` 同一份权重。
奶油肌 0.3（红黄与参考一致、亮度少约 3）、深色内景 1.0。

### 4.6 脸部遮罩归属（`cream.rs::FaceOutlines`）
两人脸挨得近时，一个人的人脸解析裁剪框里有另一个人的脸，解析把它也标成皮肤；不处理时那片按两个人的参数各处理一遍
（IMG_5785：新娘右颊一块米黄色块、右眼睫毛发金，新郎脸上一条竖直接缝）。每张脸的遮罩去掉"别人脸轮廓内 ×（1 − 自己轮廓内）"
的部分（轮廓 = 关键点下颌线 + 额头点，羽化 0.04 瞳距）。按到脸中心的距离分配不可靠：亲吻照里大脸的尺度大，被吻的额头按尺度算
离大脸更近。

### 4.7 其余共用算子
祛斑（`blemish.rs`：长条 / 大面积响应剔除，纹身、法令纹不当斑）、疤痕修复（`heal.rs`）、AI 瑕疵（ABPN）、身体遮罩的颜色
连续性修正（`continuity.rs`：有色光下漏检的皮肤按边界色差找回；反方向会吞掉米色西装，不做）、颈纹淡化（`neck.rs`：
异物门控保住项链、纹身、胡茬）、眼部清晰、形变（`warp/`）。都在奶油肌阶段按像素蛋糕奶油肌校准，深色内景直接沿用。

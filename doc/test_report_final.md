# 最终测试报告：「奶油肌」与「婚纱-深色内景」两个预设

日期：2026-09-27。两个内置预设分别对两批照片做批处理，与像素蛋糕同名预设的导出逐项对比，并把结果放进最终对照组
（`out/最终对照组/`：对比图与分析入库，全尺寸批处理输出不入库）。

- 原片（`test/原片/`，7 张）：两个预设都有像素蛋糕的导出（`test/像素蛋糕“奶油肌”预设产物/`、
  `test/像素蛋糕“婚纱-深色内景”预设产物/`），做定量对比；
- 批量测试（`test/批量测试/`，15 张）：没有参考导出（其中 1V3A2954 与原片同一张），用于检查泛化与稳定性。

复现：

```bash
cargo build --release

  retouch batch -i test/批量测试 -o out/最终对照组/<预设>/批量测试 --preset $p --landmarks-dir out/最终对照组/<预设>/批量测试/_landmarks
done
python tools/sample_montages.py final                           # 五列对比图 → out/最终对照组/对比图/
python tools/image_delta.py  --orig test/原片 --ref <参考目录> --ours out/最终对照组/<预设>/原片          # 整图色差
python tools/batch_compare.py --orig test/原片 --ref <参考目录> --ours out/最终对照组/<预设>/原片 \
    --landmarks out/最终对照组/<预设>/原片/_landmarks                                                   # 逐脸

    --landmarks out/最终对照组/<预设>/原片/_landmarks                                                   # 皮肤平整度
```

## 4. 本轮在最终对照组里发现并修正的问题

### 4.1 深色内景：脸"敷粉"、缺立体感
五列对比里本程序的脸比参考更平、更像敷了粉（1V3A3127 新娘、新郎最明显）。两个原因：
- **磨皮过重**。上一轮为压 IMG_5785 的色块把 detail 调到 0.45——那处色块后来查明是遮罩越界（§4.4），磨皮不该背锅。
  像素蛋糕开了"质感保留 0.7"：毛孔一级（0.008–0.016 瞳距）只轻压，中性灰只压斑驳一级。1V3A3127 新娘参考
  0.72 1.02 0.93 0.82 1.05，本程序 0.64 0.74 0.66 0.72 0.92。
- **没有"中性灰立体"**。像素蛋糕把 0.06–0.25 瞳距的五官与轮廓明暗加强（相对只调色 α 1.02–1.11），本程序按像素亮度
  提亮、压高光反而把它压平（α 0.98–1.03）；脸部亮度标准差参考比本程序高 1～1.5（3127 新郎 11.1 / 9.7）。

修正：新增"立体"（`CreamParams::stereo`：脸部遮罩内归一化低通 σ 0.06 与 0.25 瞳距之差按比例加回，眼、眉、嘴、头发、
背景不参与取样），在 13 张脸上扫参定为女 0.22、男 0.32；磨皮改为女 0.33 / 0.15 / 0.50、男 0.33 / 0.10 / 0.50（毛孔多留、
斑驳照压）。带通中位比与参考的总偏差 女 0.31 → 0.22、男 0.35 → 0.16；逐脸"低频"差 −0.07 → −0.02；大尺度增益与参考
一致（上表）。扫过的组合（detail / fine / low、细颗粒分界 fine_sigma、立体下限 0.03 与 0.06）记录在
doc/analysis/wedding_dark_interior.md §3.2。

### 4.2 奶油肌：牙齿与遮罩越界
- 像素蛋糕奶油肌同样美白牙齿（"牙齿美白 0.4"），本程序奶油肌原来不做：1V3A3101 牙齿与参考差 ΔE 6.7。开 0.3 后红度、
  黄度与参考一致，亮度仍少 3.4（ΔE 3.5；像素蛋糕的"明度"与"祛黄"是两个独立滑块，本项目的模型用同一个拉力）。
- 脸部遮罩越界在奶油肌下同样存在，只是看不出；修掉后 IMG_5785 新郎细颗粒 0.88 → 0.93（参考 0.94）、色度带差
  −0.08 → −0.02，两张脸的皮肤色差中位 1.38 / 1.24 → 1.32 / 1.19。
- 只影响露齿与脸挨得近的照片：原片 1V3A2954、1V3A3101（只有牙齿）、IMG_5785，批量测试中贴脸 / 亲吻的几张；
  其余逐字节不变。逐脸指标整体持平或略好（纹理 −0.02 → −0.01，黄度差 0.3 → 0.2）。算子默认值不变，不用预设时的
  输出不变。

## 6. 与像素蛋糕仍有的差异
本项目是独立实现、常数在导出图上拟合，与像素蛋糕不可能逐像素相同。按影响从大到小：
- 深色内景的肤色：比例模型是跨脸的折中，逐脸残差 ±1～3（1V3A2922 少黄 3.5～4.9、1V3A3101 多黄 1～2、IMG_5785
  多黄约 1.5、2954 暗约 3）；像素蛋糕的"AI 肤色统一"逐脸自适应，未复现。
- 深色内景的调色自适应：1V3A2922（晴天蓝海）、1V3A3150（阴天海滩）、1V3A2954 的背景与参考差 ΔE 约 2（p90 5～6）。
- 男性下巴 y 差 −12～−18（1V3A2922、3127、3150）：像素蛋糕"祛双下巴"改了下巴下方的明暗，光流测到的不是形变。
- 未模拟：祛双下巴、祛眼周纹、祛碎发、唇纹修整、头发柔顺、牙齿祛瑕疵 / 排齐、AI 面部流畅、去亮片（IMG_5770 新娘额头
  的亮片，像素蛋糕深色内景去掉了）。
- 1V3A3127 胸口上沿一片高光仍未被身体色调外溢覆盖（doc/test_report_wedding_dark_interior.md §6）。

# 测试报告：「奶油肌」身体皮肤上的阴影色块

日期：2026-09-26。问题：批量对比图 `out/对比图/批量测试/` 里，女性肩膀、锁骨、胸口上出现一块块边界清晰的
"阴影色块"（1V3A2889 的肩膀、1V3A2957 与 1V3A2958 的胸口和肩膀、1V3A2837 的胸口与抬起的手臂），原图上没有。

复现与评估命令：

```bash

retouch batch -i test/批量测试 -o out/batch_test --preset cream --landmarks-dir out/batch_test/_landmarks
# 身体遮罩等调试输出（每张照片一个子目录）
retouch apply -i <原片> -o x.jpg --preset cream --debug-dir <调试目录>/<照片名>

# 身体色调相对像素蛋糕（新的比例降黄模型的拟合与评估）
```

对比图清单见 out/README.md 的 `blotches/` 一节。

## 1. 分析

**色块是没被处理的皮肤。** 身体遮罩内的皮肤被提亮（女性约 +4.6 L）、降红、降黄、磨皮，遮罩外保持原样；
遮罩在连续的皮肤中间留下空洞，空洞就比四周暗 2–3.5 L、偏色，形状是颜色阈值线的"海岸线"。
逐步复现身体遮罩（`skin/masks.rs`），把每个没被处理的皮肤像素（语义皮肤概率 > 0.7、在人像抠图内）归到第一个
把它排除的环节：

| 区域 | 没被处理的皮肤（像素） | 颜色规则排除 | 形态学清理 | 其余 | 颜色规则中不通过的条件 | 空洞 / 已处理皮肤的 b（中位） |
|---|---|---|---|---|---|---|
| 1V3A2889 肩膀 | 24687 | 91% | 2% | 7% | G > B 97%、Cb 32%、饱和度 27% | 1.5 / 11.3 |
| 1V3A2957 胸口 | 106788 | 91% | 9% | 0% | G > B 100% | 2.8 / 7.0 |
| 1V3A2837 胸口 | 17931 | 92% | 8% | 1% | 饱和度 95%、Cr 44% | 3.5 / 12.3（L 75，高光） |
| 1V3A2958 胸口与肩 | 239507 | 96% | 4% | 0% | G > B 100% | 1.8 / 8.2 |

**原因：严格肤色规则的固定阈值在有色光下失效。** 身体遮罩 = 人像抠图 ∧ 严格肤色规则（`mask::is_skin_strict`：
Cr 135–173、Cb 77–127、R > G > B、饱和度 0.10–0.62）∧ 语义皮肤概率。天光照亮的皮肤（朝天的肩膀、游艇上的
胸口与手臂）偏蓝，蓝分量追上绿分量；阳光直射的高光饱和度低于 0.10；红色影棚里被红墙染红的暗部 Cr / 饱和度
超上限。语义模型与抠图都认为这些是皮肤，只有颜色规则拒绝。0.6.1 把女性身体提亮到 4.6 L 的平台，落差随之
变大；这套颜色规则从 0.5.0 起就有。

**1V3A2837 抬起的手臂是另一种情况。** 语义模型在整条手臂上几乎都判为 0（不是皮肤），只留了一条窄条；
颜色规则认为手臂是皮肤。窄条被处理、周围不被处理，显出一块亮斑。

**不能简单放宽颜色规则。** 在全部 22 张照片上，"语义认为是皮肤、颜色规则拒绝"的像素里还有物体：粉色玫瑰
（1V3A2922、1V3A2954）、指甲油、纹身、IMG_5785 的红色扇柄、影棚里的红围巾与"囍"字卡片。区分它们的是交界：
光照造成的偏色是渐变的，被拒绝的皮肤与已接受的皮肤之间没有真正的颜色边缘；物体与皮肤之间有。沿交界比较
两侧紧邻（3 像素）的平均颜色，取中位数（半分辨率，逐连通块人工标注）：

| 类别 | 色度差（a、b） | 亮度差（L） |
|---|---|---|
| 天光偏蓝的皮肤、高光 | 0.4–1.6（边缘的小块到 3.4） | 0.2–0.8（到 3.2） |
| 影棚里染红的手、手肘、脖子 | 0.5–1.3（指缝到 5） | 1.0–3.0 |
| 玫瑰 | 3.7–10.3 | 3.0–10.1 |
| 指甲油 | 3.8–12.0 | 3.4–16.1 |
| 纹身（IMG_5785） | 6.3 | 8.5 |
| 扇柄（IMG_5785） | 2.4 | 3.9 |
| 红围巾、"囍"字卡片 | 34–38 | 20–28 |
| 头发、黑色蕾丝、指缝深阴影 | 1.1–1.6 | 3.4–4.7（亮度 L ≈ 20） |

色度差 < 3.5 且亮度差 < 3.5、并且不太暗（L ≥ 30），就只是阈值线；这组阈值在 22 张照片上把两类分开。
余量不大：最接近阈值的物体是一朵玫瑰（色度差 4.4、亮度差 3.0）与扇柄（2.4、3.9）；把色度阈值放宽到 4.5
时多出来的 4 块都还是皮肤。

**反方向不能这样做。** "颜色规则认为是皮肤、语义模型拒绝"的像素里有米色西装、白衬衫领口、婚纱、白花、
头发（1V3A3188 / 3193 / 3194 各有上百万像素），它们与"已接受皮肤"之间也量不出边缘——语义边界本身是模糊的，
已接受的一侧已经混进了同色的衣物。语义模型对物体的否决必须保留。对 1V3A2837 这种孤岛，反过来处理：
一小块语义皮肤被同色、无边缘的"颜色认、语义拒"区域包围时，与周围一样不处理。

## 2. 改动

| 项 | 内容 |
|---|---|
| `skin::continuity`（新） | `reconcile_body_mask`：在身体遮罩的半分辨率上、语义门控之后、形态学清理之前修正遮罩。**找回**：人像内、颜色规则不通过、语义概率 > 0.7、L ≥ 30、不在物体边界（亮度梯度 > 8 或色度梯度 > 4 / 像素）上的像素取 4 连通块，与已接受皮肤的交界两侧色度差、亮度差的中位数都 < 3.5 的整块接受。**去孤岛**：面积 ≤ 4 瞳距当量²、外圈一半以上是"颜色认、语义拒"的像素、且与之无颜色边缘的已接受块去掉。只在有人像抠图与语义皮肤模型时生效 |
| 身体降黄改为比例式 | 像素蛋糕的女性身体降黄与皮肤本身的黄度成比例：b −1.5 → +1.9，b 1.6 → +0.4，b 10.7 → −1.8，b 21 → −3.6。原来的常数降黄（−2.5）会让找回的偏蓝皮肤更蓝（1V3A2922 手臂：像素蛋糕 b +0.5，常数模型 −2.3）。新参数 `body_pull_b` 0.19 / `body_target_b` 1.3（`tools/body_tone_fit.py` 在新遮罩上拟合），`body_yellow` 改作额外偏移（女性 0）。男性的降黄量与黄度几乎无关（比例拟合的残差与常数相同），保持 −1.1 |
| 重构 | 4 连通域标记（`components`）从 `skin::heal` 移到 `skin::morph`（遮罩模块不依赖修复模块），行为不变 |
| 工具 | `tools/body_tone_fit.py` 拟合比例降黄（并报告常数模型的残差作对照）；`tools/sample_montages.py blotches` 生成本问题的对比图；前后对比函数按照片名在两批样张里查找，像素蛋糕的导出有才加一列 |

## 3. 结果

**阴影色块消失**（`out/blotches/`）：1V3A2889 的肩膀、1V3A2957 与 1V3A2958 的胸口 / 肩膀 / 手臂、1V3A2837 胸口的
暗斑与手臂的亮斑、1V3A2922 整条手臂与手都处理得和周围一致。玫瑰花束、红围巾、"囍"字卡片、纹身、指甲不变。
1V3A3188 新郎的米色领结原来被语义模型当成皮肤、结上的褶皱被修复步骤抹掉一块，现在保持原样。

**回归。**
- 只看遮罩的修正（改比例降黄之前）：没有这类区域的 IMG_5770、1V3A3193、1V3A3194 输出逐像素不变，
  1V3A3188 只有领结变化；比例降黄随后改变所有女性身体皮肤的黄度（见上表）；
- 脸部：`tools/batch_compare.py` 14 张脸的各项指标不变，只有"改动面积"变大（1V3A2922 1.9% → 2.4%，像素蛋糕 2.0%）；
- 非奶油肌参数组的 golden 与 0.6.1 逐位相同；`cream_skin` 组 demo 73.9 dB、mh 54.0 dB（颈纹与身体色调），已更新；
- 测试：库的单元测试 104 个（新增颜色连续性 4 个、比例降黄 1 个）、集成测试与图形界面后端 19 个全部通过，
  `clippy -D warnings`、`cargo doc` 无告警；
- 耗时：身体遮罩这一步约增加 0.1–0.2 s（同一台机器负载不同，粗略）。

## 4. 已知局限

- 边界情况的皮肤块仍按原样不处理：交界两侧色度差或亮度差略超 3.5 的（1V3A2922 胸口玫瑰阴影里的一小块、
  影棚里手指之间的深阴影）；
- 语义模型整片漏掉的皮肤不找回（颜色规则认、语义拒的方向无法与衣物区分），只去掉其中的小孤岛；
- 颜色规则之外，语义模型也会把粉色玫瑰当成皮肤——玫瑰上通过颜色规则的部分仍被处理（与修改前相同）；
- 另发现（与本问题无关，未修改）：1V3A2889 下巴右侧天空里的一小块白斑——下巴与天空亮度接近，脸部遮罩的导向
  羽化沿下颌漏进一条天空，被当作皮肤处理，缩下巴形变后露出。

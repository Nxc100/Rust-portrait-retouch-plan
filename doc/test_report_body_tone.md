# 测试报告：「奶油肌」身体色调——腋下褶纹没有被自然抹平

日期：2026-09-26。问题：IMG_5785 新娘腋下的褶纹在「奶油肌」输出里仍然很深，像素蛋糕的导出则明显更柔和。

复现与评估命令：

```bash
# 每张原片导出身体遮罩与关键点（调试目录按照片名分子目录）
retouch apply -i test/原片/IMG_5785.jpg -o out/x.jpg --preset cream --debug-dir <调试目录>/IMG_5785
# 拟合 / 评估身体色调（--ours 给出本项目的批处理输出）
python tools/body_tone_fit.py --orig test/原片 --ref "test/像素蛋糕“奶油肌”预设产物" \
    --debug <调试目录> --ours out/batch [--fit-shape]
# 脸部指标回归
python tools/batch_compare.py --orig test/原片 --ref "test/像素蛋糕“奶油肌”预设产物" \
    --ours out/batch --landmarks out/batch/_landmarks
# 修改前 / 后对比图（原图 | 修改前 | 修改后 | 像素蛋糕）→ out/body_tone/
python tools/sample_montages.py body
```

对比图、亮度变化热图与评估输出见 `out/body_tone/`（清单见 out/README.md），其中
`compare_IMG_5785_armpit.png` 即本问题的腋下褶纹。

## 1. 分析

**遮罩不是原因。** 腋窝整块都在身体遮罩内（褶线处遮罩均值 0.90、语义皮肤概率 0.88）。

**频段统计。** 腋窝凹陷内（瞳距当量 267 px），输出相对原图的频段 RMS 比：

| | 中频 1.3–9.3 px | 低频 9–27 px | 褶皱 27–67 px | 平均 L |
|---|---|---|---|---|
| 本项目（修改前） | **1.060** | 0.980 | 0.959 | +2.1 |
| 像素蛋糕 | 0.964 | 0.911 | 0.850 | +4.8 |

本项目的中频反而被放大，更粗的褶皱阴影几乎不动；像素蛋糕把凹陷整体提亮、褶皱变浅。
沿褶线的横截面上，像素蛋糕在 L 43–58 的暗部提亮 +6 ~ +7、亮处 +4.7，本项目暗部只有 +0.2 ~ +1.7。

**原因。** 身体色调原来按**像素**亮度加权：`ΔL = 2.4·clamp((L − 30)/30)`。
1. L 30–60 之间斜率为 1 + 2.4/30 = 1.08：局部对比被放大 8%，暗褶纹越暗、提得越少，于是更深；
2. L < 30 完全不提亮，高光（L > 60）反而提满——与像素蛋糕相反。

**像素蛋糕的身体色调。** 7 张照片、身体皮肤按最近的人脸分到各人，按低频亮度（σ = 0.03 瞳距当量）分箱的 ΔL：

| L | 24 | 32 | 40 | 48 | 56 | 64 | 72 | 80 |
|---|---|---|---|---|---|---|---|---|
| 新娘（6 张的范围） | +4.2 ~ +4.8 | +2.2 ~ +4.8 | +2.4 ~ +5.5 | +2.5 ~ +6.6 | +2.6 ~ +6.3 | +1.5 ~ +5.1 | +0.3 ~ +3.5 | −0.2 ~ +2.3 |
| 新郎（脖子、手） | +3.0 ~ +4.8 | +1.3 ~ +4.9 | +1.8 ~ +3.7 | +0.6 ~ +4.5 | +0.6 ~ +4.7 | +0.3 ~ +4.0 | +1.2 ~ +2.6 | |

——阴影到中间调是一个平台，高光渐弱；新郎的提亮约为新娘的一半（新娘搭在新郎肩上的手只提了 +0.6，
说明像素蛋糕也按人区分）。检验过"比周围暗的区域额外提亮"（专门针对褶皱的提亮）：加入该项后系数为负、
RMS 1.80 → 1.78，没有这种机制，不采用。

## 2. 改动（`src/skin/cream.rs` 第 5 步的身体分支）

| 项 | 内容 |
|---|---|
| 只看低频亮度 | 提亮与降黄的权重由遮罩内归一化卷积的低频亮度决定（`masked_gaussian`，σ = 0.03 瞳距当量）：同一块皮肤上的暗褶纹与周围提得一样多，局部对比不变；遮罩外的背景 / 衣物不参与平均，皮肤边缘不出光圈 |
| 提亮形状 | `ΔL = body_lift · [0.8 + 0.2·S(20, 44, L)] · [1 − 0.9·S(64, 88, L)]`（S 为 smoothstep），在全部身体像素上网格搜索得到 |
| 按人 | 身体像素按到各张脸中心的距离（以该脸尺度为单位）软分配，权重 ∝ exp(−(d − d_min)/0.5)，混合各人（性别不同）的 `body_lift / body_redness / body_yellow`；各人参数相同时直接用常数 |
| 参数 | 女（及未知性别）提亮 4.6、降红 −0.85、降黄 −2.5；男 2.6、−0.6、−1.1（原来一律 2.4、−0.5、−2.2） |
| 工具 | `tools/body_tone_fit.py`：拟合形状与各性别参数，并评估任意输出相对参考图的身体色调偏差 |

身体的其余处理（三频段磨皮、匀肤、瑕疵 / 疤痕修复）不变，仍用 `body_params`（预设的女性档）。

## 3. 结果

**腋窝凹陷**（同 §1 的区域）：

| | 中频 | 低频 | 褶皱 | 平均 L |
|---|---|---|---|---|
| 修改前 | 1.060 | 0.980 | 0.959 | 59.9 |
| 修改后 | 0.984 | 0.895 | 0.856 | 62.3 |
| 像素蛋糕 | 0.964 | 0.911 | 0.850 | 62.6 |

按局部中频能量分箱，修改后每一档的中频衰减都不少于像素蛋糕；凹陷变亮、主褶线变柔，细纹程度与像素蛋糕相当。

**7 张照片的身体色调**（相对像素蛋糕的低频变化之差，偏差 / RMS；只计归属权重 > 0.8 的像素）：

| | dL | da | db |
|---|---|---|---|
| 新娘 修改前 → 后 | −0.90 / 2.62 → +0.01 / 1.70 | +0.31 / 1.29 → −0.04 / 1.23 | +0.16 / 1.17 → −0.11 / 1.17 |
| 新郎 修改前 → 后 | −0.17 / 1.47 → −0.10 / 1.56 | −0.08 / 0.83 → −0.16 / 0.83 | −1.25 / 1.52 → −0.26 / 0.96 |

新娘 6 张全部改善（IMG_5785 2.83 → 1.40）。新郎的亮度 RMS 略升，主要来自 1V3A3150——只检测到新郎一张脸，
新娘的手臂被归给了新郎（提亮 2.6，修改前也只有约 2.4），这是漏检的已有局限。

**回归。**
- 脸部：`tools/batch_compare.py` 14 张脸的各项指标不变（平均下巴 y 差 −0.4 → −0.5 px，脖子变亮影响下颌线测量）；
- 非奶油肌参数组（手动、自然磨皮、gpupixel、LUT）的输出与修改前逐位相同；
- `--no-body` 时脖子仍按身体处理（`masks.rs` 的脖子多边形），因此脖子的色调随之变化，其余不变；
- golden：`cream_skin` 组 mh 样张 PSNR 45.4 dB（身体约 6% 像素变化），已按有意的改动更新（`UPDATE_GOLDEN=1`）；
- 耗时：身体色调 5 ms → 54 ms（单人）/ 约 200 ms（两人），整张 20–30 MP 约 11–14 s。

## 4. 已知局限

- IMG_5770 的新娘身体像素蛋糕只提了约 +2.3，本项目按女性档 +4.6，偏亮 1.8（6 张新娘里唯一的例外）；
- 人脸漏检时，此人的身体按最近的已检测人脸取参数；
- 身体色调之外的身体参数不分性别。

# 测试报告：「婚纱-深色内景」预设

日期：2026-09-26 初版；2026-09-27 按使用反馈修正（§4）。目标：新增内置预设「婚纱-深色内景」，效果对标像素蛋糕
同名预设的导出图（`test/像素蛋糕“婚纱-深色内景”预设产物/`，7 张原片），不影响「奶油肌」与其他已有功能。
模型与拟合过程见 doc/analysis/wedding_dark_interior.md。

复现与评估命令：

```bash
retouch batch -i test/原片 -o out/batch_dark_interior --preset 婚纱-深色内景 --landmarks-dir out/batch_dark_interior/_landmarks
retouch batch -i test/批量测试 -o out/batch_test_dark_interior --preset 婚纱-深色内景 --landmarks-dir out/batch_test_dark_interior/_landmarks

python tools/batch_compare.py --orig test/原片 --ref "test/像素蛋糕“婚纱-深色内景”预设产物" \
    --ours out/batch_dark_interior --landmarks out/batch_dark_interior/_landmarks
# 脸部皮肤的平整度（带通中位幅度比，磨皮校准）
python tools/skin_bands.py --orig test/原片 --landmarks out/batch_dark_interior/_landmarks     --ref "test/像素蛋糕“婚纱-深色内景”预设产物" --ours 定稿=out/batch_dark_interior
# 牙齿美白权重（与流水线同一份）：--debug-dir 下的 teeth.png
retouch apply -i test/原片/1V3A3101.JPG -o out.jpg --preset 婚纱-深色内景 --debug-dir <调试目录>
# 调色的拟合与留一评估（--debug 为每张照片 `retouch apply --preset cream --debug-dir` 的输出）
python tools/grade_fit.py --orig test/原片 --ref "test/像素蛋糕“婚纱-深色内景”预设产物" --debug <调试目录> \
    --size 17 --smooth 3e-3 --loo [--cube luts/wedding_dark_interior.cube --title 婚纱-深色内景]
# 完整对比图 → out/对比图/婚纱-深色内景/
```

## 4. 使用反馈与修正（2026-09-27）
反馈：IMG_5785 新娘脸上有色块、皮肤的自然与光滑程度与像素蛋糕差距明显；IMG_5785 新郎同样不够光滑；1V3A3101 新娘
胸口有黄色色块；没有像素蛋糕会做的牙齿美白。「奶油肌」没有这些问题，原因各不相同：奶油肌的磨皮是直接对着
奶油肌导出校准的；身体色调轻（提亮 4.6、黄度拉力 0.19，本预设 6.8 / 0.67），漏检皮肤看不出；没有预设调色；
本项目的奶油肌不做牙齿美白。

### 4.1 脸：磨皮按"中性灰平整"重新校准
初版按纹理 RMS 能量比把磨皮调轻（女 0.30 / 0.10、男 0.15 / 0.03），被像素蛋糕清晰度 / 对比度放大的强边缘误导
（analysis §3.2）。改按皮肤带通的中位幅度比校准，定稿女 0.45 / 0.15 / low 0.40、男 0.45 / 0.05 / low 0.50：

| 0.032 瞳距一档（中性灰平整的尺度） | 像素蛋糕 | 修改前 | 定稿 |
|---|---|---|---|
| 女（6 张脸平均） | 0.78 | 0.86 | 0.75 |
| 男（7 张脸平均） | 0.82 | 0.95 | 0.75 |
| IMG_5785 新娘 | 0.80 | 0.98 | 0.80 |
| IMG_5785 新郎 | 0.77 | 0.83 | 0.70 |

目视（`out/对比图/婚纱-深色内景/原片/IMG_5785_脸1.jpg`、`脸2.jpg`）：两张脸的明暗斑块消失，平滑程度与参考接近。
（最终对照组里又按"质感保留"与"中性灰立体"重新校准为 0.33 / 0.15 / 0.50 + 立体，见 doc/test_report_final.md §4.1。）

### 4.2 胸口的黄色色块：肤色外溢
语义皮肤模型漏掉了贴着红礼服的胸口（红色反光），该预设较强的身体色调让漏掉的一片成了黄色色块。新增
`skin::spill`（analysis §3.3）后，Lab 均值（修改前 → 定稿，像素蛋糕）：

| 位置 | 修改前 | 定稿 | 像素蛋糕 |
|---|---|---|---|
| 1V3A3101 胸口贴裙一条 | 80.8 / 18.9 / 24.2 | 82.6 / 17.0 / 15.4 | 79.9 / 14.5 / 12.3 |
| 1V3A3127 左胸贴裙 | 85.8 / 13.1 / 22.9 | 86.6 / 10.9 / 14.4 | 84.1 / 10.3 / 13.7 |

外溢的改动只落在皮肤上：7 张原片与不做外溢相比，ΔE > 2 的像素集中在 3101、3127 的胸口与手；1V3A2954、1V3A2922
的粉玫瑰只有花瓣边缘零星几点（色相门限挡住了其余）。

### 4.4 脸上仍有色块：脸部遮罩越界（第二轮反馈）
反馈：IMG_5785 新娘脸上仍有色块。全分辨率下是右颊外侧一块偏米黄、边界分明的区域，右眼睫毛发金铜色；按亮度分档
与区域均值比较，本程序与参考只差 1～2，问题在空间上。调试遮罩显示新郎的解析遮罩越界盖住了新娘的右颊与右眼
（新娘的也盖住新郎左半边脸），那片按两人的参数各处理一遍（analysis §3.4）。修正后（`face_ownership`）：

|---|---|---|---|
| 5785 新娘 0.032 瞳距带通比 | 0.86 | 0.80 | 0.80 |
| 5785 新娘右颊外侧 | 米黄色块、边界分明 | 与脸颊连贯 | 连贯 |
| 5785 新娘右眼睫毛 | 金铜色 | 与只调色一致 | 深色 |
| 5785 新郎 | 左半边多一遍女性处理，中间竖直接缝 | 整张脸一致 | 一致 |

受影响的只有脸挨得近的照片：原片 IMG_5785，批量测试 1V3A2837、3188、3194（贴脸 / 亲吻，越界更大，修正后各自只按
自己的参数处理）、3122（少量）；其余 17 张逐字节不变。「奶油肌」不开这一项，44/44 仍逐字节相同。

### 4.5 人物主体的误检块
1V3A3127 背景墙上的圆形灯饰被人像 alpha 当成人物，主体提亮后成了一块亮斑；`subject_weights` 去掉与人脸不相连的
小块后消失。

## 5. 回归
- 「奶油肌」：用新程序重跑两批 22 张，成片与关键点 JSON 与改动前**逐字节相同**（44/44）；预设不带 `grade`，
  `body_tone_spill` 与 `teeth_whiten` 为 0，流水线与原来完全一致。
- 保边底图从 `color::develop` 移到 `skin::guided`，实现逐字相同，develop 的单元测试不变。
- 单元测试 130 个（初版之后新增外溢 5 个、牙齿 3 个、主体权重 1 个、脸部遮罩归属 1 个）、恒等性 10 个、图形界面 19 个；golden 的
  `wedding_dark_interior` 一组按定稿重新生成，其余 14 张与改动前一致（样张没有挨得近的两张脸）。
- 整图与像素蛋糕的 ΔE（§1）不变（平均 1.61）：这些修正都是局部的。处理时间 8.8 s / 张（奶油肌 8.0 s）。

## 6. 已知局限
- 像素蛋糕的自适应规则未知，自适应黑点是近似；1V3A2922（晴天蓝海）与 1V3A3150（阴天海滩）的背景留一误差仍约 5；
  样本多为户外，真正的深色室内场景没有参考。
- 肤色的比例模型是跨脸的折中：1V3A2922 的皮肤在调色后偏蓝，拉回后仍比参考少黄（偏粉）。
- 1V3A3127 胸口上沿一片高光（比已接受的肩颈皮肤亮 8、红度与黄度各低 6）仍未被外溢覆盖，b 20 对参考 12；放宽门限
  会把贴着皮肤的象牙色 / 香槟色婚纱当成皮肤。
- 肤色是跨脸拟合的比例模型：IMG_5785 新娘比参考黄约 1.7、腮红更淡（女性平均反而少黄 0.4）。
- 牙齿：像素蛋糕的牙齿祛瑕疵去掉了像素级噪点、牙齿排齐改了牙形，不模拟。
- 未模拟：祛双下巴、祛眼周纹、祛碎发、唇纹、头发柔顺、小腿。

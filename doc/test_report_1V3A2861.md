## 3. 效果观察（`out/pipeline_1V3A2861/montage_*.png` 对比图）

- **磨皮 A（默认 smooth 0.5）**：毛孔明显柔化，眉毛 / 眼睫 / 发丝保留；log 提亮 + HSB(1.1, 1.1) 作用于全图，海面与天空同样变亮变饱和（忠实还原原实现）。
  不希望改背景时加 `--no-log --brightness 1 --saturation 1`。
- **磨皮 B（freqsep 0.75）**：保留皮肤纹理，只压低暗斑对比，效果自然但较轻；28MP 下高反差遮罩由短边 1000 的工作副本上采样，1:1 观察无块状痕迹。
- **磨皮 C（gpupixel 1.0）**：比 A 更平，新郎脸颊略显"塑料感"（强度 1.0 所致），锐化项保留了部分毛孔。
- **形变（瘦脸 0.7 / 大眼 0.5 / 瘦鼻 0.6）**：两张脸均变窄、眼睛变大，无撕裂 / 黑边，边界无可见接缝；2d106 与 Face Mesh 两套关键点结果一致。
- **美白 0.35 + 暖调 LUT 0.5**：肤色提亮通透，LUT 使整体偏暖（示例 LUT，强度可调）。
- **遮罩**（`out/pipeline_1V3A2861/montage_masks.png`）：人脸多边形遮罩为两个羽化的"水滴"；颜色肤色规则把礁石与新娘的颈 / 肩 / 手臂也判为肤色，
  因此默认 `restrict_to_face` 只处理脸部，礁石不受影响，但颈肩也不会被磨皮 / 美白。

## 4. 发现的问题与建议

1. **颈肩未处理**：婚纱照常需要颈、肩、手臂一起磨皮 / 美白。当前只能用 `--no-face-restrict`（会连礁石一起处理）。
   建议后续给人脸多边形增加"颈部延伸"（沿 dir_up 反向延伸 0.8–1.0 倍脸高的梯形并羽化），或接入人像分割。
2. **全图提亮**：A 模式默认的 log + HSB 改变背景是原实现行为，作为修图软件建议 UI 默认关闭 `apply_log_curve`，
   把亮度 / 饱和滑块默认置 1.0。
3. **大图 I/O 占大头**：28MP JPEG 解码 + 编码约 1 s，超过修图本身；预览链路应复用一次解码的缩略图。

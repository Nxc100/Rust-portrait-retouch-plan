# 测试报告：「奶油肌」颈纹——女性脖子上的皱纹没有被磨平

日期：2026-09-26。问题：批量对比图 `out/batch_compare/1V3A2922_f1.png`（原图 | 像素蛋糕 | 本程序）里，
像素蛋糕把新娘脖子上的皱纹磨平了，本程序的脖子上仍有明显的皱纹。

复现与评估命令：

```bash
# 当前版本
retouch batch -i test/原片 -o out/batch --preset cream --landmarks-dir out/batch/_landmarks
# 修改前：关掉颈纹这一步（与 0.6.1 的输出逐字节相同）
retouch batch -i test/原片 -o out/_work/neck_before --preset cream --no-report \
    --set cream_female.neck.strength=0 --set cream_male.neck.strength=0 --set cream_unknown.neck.strength=0
# 颈纹的处理权重（调试导出 neck_zone.png，与皮肤遮罩等在同一目录）
retouch apply -i test/原片/1V3A2922.JPG -o out/x.jpg --preset cream --debug-dir <调试目录>
# 对比图：原图 | 修改前 | 修改后 | 像素蛋糕 → out/neck/；逐脸对比 → out/batch_compare/
python tools/sample_montages.py neck batch
# 脸部指标回归
python tools/batch_compare.py --orig test/原片 --ref "test/像素蛋糕“奶油肌”预设产物" \
    --ours out/batch --landmarks out/batch/_landmarks
```

对比图清单见 out/README.md；`out/neck/compare_1V3A2922_bride_neck*.png` 即本问题。

下文的统计都在**原图几何**里做：输出先用 DIS 光流对齐到原图（像素蛋糕与本程序都有瘦脸 / 缩下巴形变），
区域为人脸解析的脖子类 ∩ 身体遮罩。深度、能量的单位为 Lab 的 L。

## 1. 分析

**脖子上没有针对颈纹的处理。** 0.6.1 的脖子按身体皮肤处理（三频段磨皮 + 匀肤），颈纹只被略微减弱。
新娘（1V3A2922，瞳距当量 160 px）脖子上按深度分档的谷填充 / 脊压低比例（1 = 抹平，0 = 不变）
与按局部中频能量分档的中频保留比例：

| | 谷填充 深 1–2 / 2–3 / 3–5 / 5–8 / 8–14 | 脊压低（同档） | 中频保留 E 0–1 / 1–2.2 / 2.2–3.2 / 3.2–4.5 / >4.5 |
|---|---|---|---|
| 像素蛋糕 | 0.69 / 0.65 / 0.54 / 0.34 / 0.18 | 0.53 / 0.53 / 0.45 / 0.24 / 0.18 | 0.53 / 0.33 / 0.46 / 0.86 / 0.95 |
| 0.6.1 | 0.62 / 0.44 / 0.31 / 0.20 / 0.12 | 0.33 / 0.22 / 0.13 / 0.10 / 0.09 | 0.59 / 0.61 / 0.80 / 0.92 / 1.00 |

**像素蛋糕做了什么。**
1. **对称的保边平滑**：暗纹与两侧的亮脊一起被压平（脊压低与谷填充相当），颈纹所在的中等能量
   （E 1–3.2）只留三到五成；本来平滑的皮肤（E < 1）与强边缘（E > 4.5）基本不动。手臂、胸口没有这一步。
2. **细线被直接填平**：对齐后的改动图（像素蛋糕 − 原图，去掉整体色调）上是一根根锐利的亮线，恰好贴着
   每一条颈纹的线芯和横过脖子的碎发——线被填平，周围的细颗粒不动。原图上是"细长暗线"的像素
   （方向线段闭运算量出的线深 3–6 L 以上，见 §2），像素蛋糕把平均线深 6.91 压到 2.30，
   其余像素的纹理（同一算子量出的起伏）0.65 → 0.39。
3. **保留**：项链与它投在皮肤上的影子、两位新郎颈部的纹身（连同笔画淡下去的尾迹）、胡茬、下颌轮廓
   （脖子周围最强 3% 的结构梯度保留 0.96）。
4. 男女都做，强度因照片而异（1V3A3127 新郎的线深 5.41 → 2.11，1V3A2954 新郎 5.44 → 4.26）。

0.6.1 的问题因此有两层：没有第 1 项；即使加上第 1 项，平滑作用在去掉细颗粒的底层上，锐利的线芯与碎发
留在细颗粒里（只做第 1 项时新娘的线深 3.17，像素蛋糕 2.30），按对比图的尺度看仍是一道道皱纹。

**难点：脖子上的异物。** 项链（金属灰，色度只有皮肤的 0.35–0.45）投在皮肤上的影子是皮肤色的细暗线；
纹身墨迹的色度约为皮肤的七成，笔画淡下去的尾迹是皮肤色、深度与颈纹相当（IMG_5770 的尾迹深 8–9 L、
色度比 1.05）；碎发的色度与皮肤接近（棕色发丝 24 vs 皮肤 22）。早期版本只按色度排除异物，
IMG_5770 的纹身被抹淡（最大改动 33/255）；对应的判据见 §2。

## 2. 改动（`src/skin/neck.rs`，奶油肌第 7 步）

在脸部、身体处理之后，对每张有人脸解析的脸单独处理它的脖子，尺度用该脸的瞳距当量（ed）：

| 项 | 内容 |
|---|---|
| 区域 | 解析的脖子类（羽化 0.04 ed）× 身体遮罩 × 语义皮肤门控 × 异物门控；在解析图覆盖范围自己的边缘渐隐（图像边缘不渐隐，画面外没有脖子）；可见面积小于 0.02 ed² 时跳过。区域在**处理前**的颜色上确定 |
| 两人的脖子 | 贴脸、亲吻时一张脸的解析范围会盖到另一个人的脖子：脖子像素按与身体色调相同的归属规则（到各张脸中心的距离以该脸尺度计，软度 0.5）分给各人，每个像素合计只处理一次，用它主人的参数与尺度 |
| 异物 | 色度 / 脖子皮肤色度 < 0.55–0.8，或灰度闭运算（窗口半宽 0.05 ed）的黑顶帽深 10–16 L 以上；异物之间窄于约 0.16 ed 的缝连成一片（纹身笔画间的淡尾迹、并排的链条之间），再外扩 0.03 ed（项链的影子、描边） |
| 平滑 | `Ls = G(L; σf)`（σf 与三频段磨皮相同，但不低于 1 px）；异物像素用周围皮肤的归一化平均填上得到 `Lk`；`S = GF(Lk; 0.05 ed, eps 80)`（导向滤波）；在局部中频能量 0.4→0.8 渐入、6→12 渐出的窗口内加 `strength·(S − Lk)` |
| 细线填平 | `morph::dark_line_depth`：8 个方向上各用长 0.08 ed 的线段做灰度闭运算，取各方向的最大减最小——暗线只在横跨它的方向被填平，差即线深；比线段短的暗点（胡茬、毛孔、痣）为 0。原图上线深 3→6 L 渐入、12→20 L 渐出（太深的是项链的影子、深色发丝、纹身，连同周围 0.03 ed 不算）的像素是"线"；平滑之后在当前图上再量线深，按 `line_fill` 填平——不会比两侧更亮，细颗粒原样保留。线深在区域四周外扩一个线段半长量，图像外按边缘像素延拓：区域与图像边缘处的明暗台阶不会被量成线 |
| 参数 | `CreamParams::neck`（`NeckParams`）：`strength` 1.0、`radius` 0.05、`eps` 80、`energy_lo` 0.8、`energy_hi` 6、`line_fill` 1.0，男女相同；`presets/cream_skin.json` 已重新生成。`strength = 0` 关闭整步 |
| 调试 | `retouch apply --debug-dir` 在奶油肌模式下多导出 `neck_zone.png`（`Engine::neck_weights` → `pipeline::cream_neck_weights` → `cream::neck_weights`） |

配套的库改动（行为不变）：新模块 `skin::morph`（方形窗口的膨胀 / 腐蚀 / 闭运算、方向线段的线深）；
`ParseMap::mask_in`（解析类在任意窗口里的遮罩，`mask_of` 改为调用它）；`masked_gaussian` / `subsample_for`
从 `cream.rs` 移到 `guided.rs`，`smoothstep` 移到 `skin` 模块共用；身体的语义皮肤门控抽成 `semantic_skin_gate`。
图形界面"处理身体皮肤"开关的提示注明了颈纹淡化（它依赖身体遮罩）。

**取舍。**
- `line_fill` 取 1.0：0.6 时按对比图的尺度仍能看到淡淡的线；1.0 的线深（1.61）低于像素蛋糕（2.30），
  但像素蛋糕的剩余"线深"里有它保留的更多细颗粒，看上去两者相当（`out/neck/compare_1V3A2922_bride_neck_zoom.png`）。
- 细颗粒分界不低于 1 px：三频段磨皮的下限是 0.5 px（中频只是部分平滑），这里是整段换成平滑结果，
  小脸（1V3A3150，ed 96）的脖子纹理会从 0.41 掉到 0.19（像素蛋糕 0.49）。
- 试过、不采用：放宽异物保护圈到 0.05 ed（多排除 5–12% 的脖子）；"与头发区域连通"的碎发识别
  （项链经过头发附近，被当成碎发）；各向同性闭运算填线（会填掉胡茬与毛孔）；导向滤波的半径 / eps 加大
  （深颈纹的指标几乎不变——瓶颈在细线，不在平滑）；按半径内最大能量关闭平滑（真实照片上无差别）。

**回归。**
- 改动范围：7 张照片与修改前相比，变化超过 3/255 的像素占 0.002%–0.056%，全在脖子上；
  脸部遮罩内每张脸 0–498 个像素（下颌交界处）；
- `strength = 0` 时 7 张输出与 0.6.1 逐字节相同——重构（`mask_in`、辅助函数迁移）没有改变已有行为；
- 脸部：`tools/batch_compare.py` 14 张脸的纹理、色调各列不变，只有下颌 x / 下巴 y 两列变化不超过 0.5%
  （由下颌附近的光流量出，脖子变了光流随之变化），平均行不变；
- 非奶油肌参数组（默认、磨皮 1.0、自然磨皮、gpupixel、美白 + 形变、只形变）的 golden 输出与修改前逐位相同；
  `cream_skin` 组 demo 74.3 dB、mh 55.6 dB（只有脖子），已更新（`UPDATE_GOLDEN=1`）；
- 测试：库的单元测试 99 个（其中颈纹 12 个、形态学 6 个、脖子归属 1 个、解析窗口 1 个为本次新增）、集成测试与图形界面后端 19 个
  全部通过，`clippy -D warnings` 无告警；图形界面冒烟测试（`gui/tests/smoke.mjs`）全部通过；
- 耗时：颈纹这一步每张 13–315 ms（第二批 7 张）、54–410 ms（第三批 15 张），整张 20–30 MP 4–14 s；
  瞳距当量约 930 px 的特写（1V3A3127 的头颈放大 3 倍，33 MP）这一步 2.1 s，整张 14.5 s。

**代码审查后的修正。** 独立审查没有发现错误，指出了两处风险与几处细节，均已修正并补了测试：
- 两张脸的解析范围盖到同一段脖子时重复处理（第二批 IMG_5785、第三批 1V3A3188 / 1V3A3194 重叠 0.4 万–4 万像素）
  → 按归属分给各人（上表"两人的脖子"）；
- 线深在区域边缘没有边距、在图像边缘被截断 → 外扩一个线段半长、图像外按边缘像素延拓；渐隐改为只在解析图
  覆盖范围自己的边缘；
- `eps ≤ 0` 会得到 NaN → 设下限；调试导出的底图与实际处理不一致（未含 AI 瑕疵补丁）→ 共用 `cream_base`。

修正前后两批 22 张输出每张最多差 9/255、不超过 444 个像素变化 > 3/255（都在脖子上），上表的指标只在小数点后
第二位变化。

## 4. 已知局限

- 很深的暗线（线深 12–20 L 以上，如浅色皮肤上的黑发）连同周围一圈保留，像素蛋糕会去掉；
- 异物周围 0.03 ed 的保护圈不处理；1V3A2954 项链旁一道与项链平行的皮肤褶影被淡化约 6 L（像素蛋糕也淡化，程度轻些）；
- 脖子上的小痣是暗点，不填（像素蛋糕去掉了新娘脖子上的一颗）；
- 男女用同一组参数：像素蛋糕对新郎颈纹的处理较轻且各张不一，四位新郎的线本程序都去得更干净；
- 已有问题，与本次改动无关：IMG_5785 新郎纹身三角内的一块淡斑来自瑕疵修复步骤；1V3A2922 的玫瑰花束被当作
  第三张脸、花束进了身体遮罩。

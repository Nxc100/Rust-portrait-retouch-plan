# 像素蛋糕「奶油肌」预设导出图的逆向分析与复现

样张：`test/1V3A2861.jpg`（28.5 MP 海边双人婚纱）→ 像素蛋糕「奶油肌」一键导出 `test/示例项目_导出/1V3A2861.jpg`。
分析脚本：`tools/compare_to_reference.py`（光流对齐 + 皮肤区域分频段 / Lab 统计）。
两轮复现的结果见 `doc/test_report_cream.md`。

## 1. 产物特征（对齐后在皮肤区域统计）

### 1.1 处理范围
- 背景（天空、海、礁石）、衣物、头发、眉眼唇：逐位不变（差异 ≈ JPEG 重编码噪声 0.5/255）。
- 脸、脖颈、胸、手臂、手：均被处理；即**人像分割 + 肤色分割**，不是人脸多边形。
- 两张脸处理强度不同：新娘（女）强、新郎（男）轻 → 预设按性别 / 人物属性分档。

### 1.2 几何（DIS 光流，单位 % 瞳距）
| 点位 | 新娘 | 新郎 |
|---|---|---|
| 下颌角 / 中下颌（向内, 向上） | (+2.2~+3.3, −2.6~−3.8) | (+1.2~+1.4, −0.5~−0.8) |
| 下巴（向上） | −4.2 | −0.2 |
| 嘴角 / 鼻尖（向上） | −2.5 / −2.0 | ≈ 0 |
| 瞳孔 / 外眼角（向中轴） | 1.1 / 1.8 | ≈ 0 |

→ 女性：整体收窄（约 0.03）+ 轻度瘦脸 + 明显缩下巴（下半脸整体上提）+ 轻度瘦鼻；无大眼。男性：只有 ~1.3% 瞳距的轻度瘦脸。

### 1.3 纹理（L 各高斯带通能量比 导出/原图，σ = 1,2,4,8,16,32 px）
- 新娘脸：0.62 0.69 0.78 0.92 0.97 1.00；新郎脸：0.77 0.74 0.75 0.87 0.95 1.00。
- 换算成**衰减剖面**（1 − √比值）：新娘 σ1 21%、σ2 17%、σ4 12%、σ8 4%、σ16 1.5%、σ32 0；新郎 12 / 14 / 13 / 7 / 2.5 / 0。
  即"轻而均匀地压细节、几乎不动 8 px 以上的光影"——不是重度磨皮；细腻感主要来自瑕疵 / 暗斑祛除、匀色和细颗粒的保留。
- 色度 a/b 各带：0.61–0.86（新娘）、0.70–0.83（新郎），σ32 仍有 0.90–0.94。
- 低频（σ16）亮度标准差不变 → **没有大尺度光影平整（中性灰）**。
- 低频色度相对皮肤均值的偏差回归斜率：新娘 a 0.87 / b 0.83，新郎 a 0.77 / b 0.70 → 肤色统一（压缩 13–30%）。

| L 区间 | 新娘 dL / da / db | 新郎 dL / da / db |
|---|---|---|
| 30–40 | −0.1 / −0.5 / −0.1 | +0.2 / 0.0 / +1.4 |
| 40–50 | +1.0 / −0.3 / +0.2 | +0.3 / −0.1 / +1.4 |
| 50–60 | +1.5 / −1.2 / −0.2 | +1.1 / −0.6 / +0.5 |
| 60–70 | +1.3 / −1.3 / −0.7 | +0.5 / −0.9 / −0.9 |
| 70–80 | +1.3 / −1.2 / −0.8 | +0.6 / −0.6 / −1.1 |
| 80–90 | +0.5 / −0.8 / −1.1 | −0.2 / 0.0 / −0.7 |
| 前 2% 高光 | −1.4 | −1.0 |

→ 中间调钟形提亮、最高光压制（去油光）、降红、高光降黄、（男性）暖阴影。

### 1.5 瑕疵
- 肩部的痣、脸颊小斑、新郎太阳穴 / 脸颊 / 下巴的痣与暗斑：全部去除，填充自然无光环，毛孔纹理连续。
- **新娘右臂 70×40 px 的疤痕（半径约 0.15 瞳距）被完全填平**，填充区保留了周围一致的皮肤颗粒。
  疤痕是"暗弧 + 亮脊"结构：在检测分辨率上带符号的 DoG 响应 ≈ 0（实测 −0.6~+0.2 L），但局部带通 RMS 是周围皮肤的 2.5–2.8 倍。
- 发丝落在胸口的阴影、指缝、鼻孔、眼角、耳廓等暗结构均**未**被当作瑕疵。
- 胸 / 手：提亮 +2.2~+2.9 L，降黄 −2.5 b，降红 −0.5 a；手部明显更平滑。

## 2. 官方文档印证
像素蛋糕「皮肤调整」包含：中性灰平整、质感磨皮、高低频磨皮（高频增强 / 低频平整）、水润磨皮、皮肤质感（哑光 / 缎面 / 水光：光泽度 / 纹理度 / 清晰度）、
肤色透亮 / 美白 / 红润 / 统一 / 色温 / 色调，以及 AI 祛瑕疵（来源：wiki.pixcakeai.com/guide/9404、14735）。
「奶油肌」预设是这些模块的一组参数组合；本分析的量化结果与"高低频磨皮（轻）+ 光泽度压制 + 肤色统一 + 透亮 + AI 祛斑祛疤"一致。

### 3.1 疤痕修复（healing brush）要点
1. 检测在瞳距 ≈ 120 px 的分辨率上进行，半径 0.025–0.16 瞳距共 5 个尺度；环核 `ring = (G(2.5r) − c·G(0.8r))/(1 − c)`，`c = (0.8/2.5)²`，
   中心权重为 0，基准不受瑕疵污染；能量判据 `RMS_in(L − G(L, r)) ≥ 3 且 ≥ 2 × RMS_ring`，且只在环 RMS ≤ 2.5 的平滑皮肤上启用。
2. 半阈值连通域（滞后）：发丝阴影 / 皱褶在半阈值下连成长条 → PCA 伸长率 > 4 或填充率 < 0.3 剔除；
   连通域边界贴着"剔除区"（遮罩边缘、强梯度、结构区）的比例 > 10% → 不是四周被平滑皮肤包围的孤立瑕疵，放弃。
3. 填充：核心向外扩 0.35r 为替换区、再 0.3r 羽化带；L / a / b 在替换区内解 Laplace 方程（粗到细 Gauss-Seidel，边界 = 周围原像素），
   得到与周围明暗 / 色度连续的低频；再从 2.2–4 倍半径处 16 个方向中选一块全在遮罩内、不含瑕疵、均值与高频能量最接近环的皮肤，
   把其 `L − G(L, 0.025ed)` 高通分量加到替换区——填充区因此有真实皮肤颗粒而非一片模糊。
4. 脸部只在"轮廓多边形内缩 0.05 瞳距 ∧ 遮罩"内检测，并扣掉眼周（0.42ed）、鼻孔 / 鼻底（0.22ed）、嘴角（0.18ed）保护区；能量判据只用于身体。

### 4.1 测量注意事项（第三轮）
- 频段比要在**未重采样**的输出上计算：光流对齐时的双线性重采样本身会削弱最细频段；做法是把原图上的遮罩按光流搬到输出图的像素网格上。
- 输出编码器必须无偏：image 0.25 的 JPEG 编码器量化前整数截断，原图直通重编码最细频段只剩 0.93（q100）；之前的纹理数字都偏低，
  换 jpeg-encoder 后直通为 1.00–1.03。
- 形变的插值同样会削弱颗粒（双线性 0.5–0.7）；现在形变用保纹理重采样（`warp/apply.rs`）。

## 5. 与参考项目的关系
- 导向滤波：He 等 TPAMI'12 / Fast Guided Filter；参考实现 `example/guided-filter`。
- FabSoften（CVPRW 2020，`example/FabSoften`，MIT）：皮肤分割 + 瑕疵检测（DoG + 轮廓）/ 修复 + 属性感知动态导向滤波 + 纹理恢复的框架；
  本项目的"先祛瑕疵、再分频段衰减、细颗粒保留"顺序与之一致。
- Poisson image editing（Pérez 等 2003，`example/poisson-image-editing`）与 Photoshop 修复画笔："明暗来自目标、纹理来自源"，对应 `heal.rs` 的调和插值 + 纹理移植。
- PatchMatch 修复（`example/PyPatchMatch`，MIT）与 LaMa（`example/lama`、`example/LaMa-OxiONNX`，Apache-2.0）：评估后未采用——
  皮肤没有需要合成的结构，调和插值 + 纹理移植更轻、更稳；LaMa 单张 512 块 CPU 需 4–7 s、模型 200 MB。
- ABPN（`example/modelscope-skin-retouching`，Apache-2.0）：AI 瑕疵分割 + 修复已集成；匀肤混合图层网络评估为"轻度匀色"，未集成。
- 人脸解析 / 抠图模型：`example/face-parsing`（MIT）、`example/MODNet`、`example/modnet-yakhyo`（Apache-2.0）。
- 高低频 / 中性灰原理：Trent1985 CSDN 专栏《影楼精修-"像素蛋糕"算法原理解析》（付费，仅公开部分）。

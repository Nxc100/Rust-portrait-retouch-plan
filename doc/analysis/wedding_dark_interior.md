# 像素蛋糕「婚纱-深色内景」预设的逆向分析与复现

样张：`test/原片` 的 7 张原片 → 像素蛋糕「婚纱-深色内景」一键导出 `test/像素蛋糕“婚纱-深色内景”预设产物/`；
另有一张 1V3A3072（1023×1537 PNG）的原图与原厂导出，作为第 8 组调色样本。
预设的参数值取自用户对像素蛋糕预设参数的分析项目（`raw/婚纱-深色内景_76316541`：精修模板与调色快照）。
**本项目只用这些参数值判断预设开了哪些功能、强弱如何；实现是自有的模型，常数全部在导出图上黑盒拟合**，
不使用像素蛋糕的代码、配置、LUT 或其他资源。复现结果见 `doc/test_report_wedding_dark_interior.md`。

## 1. 预设的构成

### 1.1 调色：一组"AI 风格"
调色快照里通用参数都是中性值，颜色全部来自 AI 风格 8（强度 100）。风格展开后分三组（滑块值，0 为不调）：

| 范围 | 主要调整 |
|---|---|
| 全局 | 曝光 −0.6 EV、对比度 +10、高光 −14、阴影 −4、清晰度 +4、鲜艳度 +10、饱和度 −5；主曲线抬黑位（0 → 10）、R 曲线中间调略抬、B 曲线暗部略压；HSL：红橙黄明度 +6～7、绿青明度 −8～9 且降饱和、蓝紫明度 −14、蓝饱和度 −8；三原色校准蓝饱和度 +7；自定义白平衡 |
| 主体（人物） | 曝光 +0.4 EV、阴影 +9、白色 +3、对比度 +3、清晰度 +7 |
| 背景 | 基本中性（曝光 −0.05 EV、高光 −2） |

即：整体压暗、高光压低、蓝紫加深、红橙黄（肤色）提亮，人物单独再提亮。

### 1.2 精修：与「奶油肌」同一套功能、强度不同
| 项目（女） | 奶油肌 | 婚纱-深色内景 |
|---|---|---|
| 质感磨皮 / 水润磨皮（脸） | 1.0 / 0.3 | 0.25 / 0 |
| 质感保留 | 0 | 0.7 |
| 中性灰平整 / 立体 | 0 / 0 | 0.8 / 0.5 |
| 肤色美白 / 透亮 | 0.15 / 0.2 | 0 / 0.25 |
| 瘦脸 / 小脸 / 下颌 | 0.15 / 0.625 / 0.5 | 0.25 / 0.6 / 0.4 |
| 眼睛整体大小 | 0.5 | 0.65 |

男性同理（质感磨皮 1.0 → 0）。另开了牙齿美白 0.3（本项目按导出拟合，见 §3.4）；祛双下巴、祛眼周纹、祛碎发、
牙齿祛瑕疵 / 排齐、唇纹修整、头发柔顺、小腿等本项目没有对应的算子，不模拟。

## 2. 调色

分析脚本在 1/8 尺寸上逐像素比较原图与导出（`tools/grade_fit.py` 的前身）；人物、皮肤与脸型变形区另行排除。

### 2.1 同一张照片内：干净的逐像素颜色映射
背景像素上按 RGB 分箱（每轴 32 格）取导出颜色的均值作查找表，一半像素建表、另一半测试，ΔE 只有 0.8–1.6；
残差随到画面中心的距离不变（±0.5 L）——**没有暗角、没有局部调整**。

### 2.2 各张之间：不是同一张 LUT
用其余照片建表预测这一张（留一），ΔE 1.7–13：

| 照片 | 不处理 | 固定 LUT | + 自适应黑点 |
|---|---|---|---|
| 1V3A2922 | 20.9 | 5.5 | 4.8 |
| 1V3A2954 | 12.5 | 5.9 | 4.7 |
| 1V3A3101 | 12.3 | 2.2 | 2.2 |
| 1V3A3127 | 10.8 | 1.9 | 1.9 |
| 1V3A3150 | 26.3 | 12.8 | 4.9 |
| IMG_5770 | 14.5 | 2.6 | 2.6 |
| IMG_5785 | 16.5 | 12.4 | 3.4 |
| 1V3A3072 | 14.2 | 2.5 | 2.7 |

中性灰像素上的色调曲线显示：1V3A3150（阴天海滩，几乎没有暗部）比其他照片压得更暗，偏差是整张图一致的亮度移动。
按直方图做的"自动色阶"能解释大部分：**没有真正暗部的朦胧 / 高调画面被压暗、加对比，有纯黑的画面不动**——
像是去朦胧。几种统计量与形式的留一比较（背景 ΔE 平均）：

| 形式 | 背景 | 说明 |
|---|---|---|
| 不做 | 5.71 | |
| 黑点 = 0.6·max(0, P2(min RGB) − 0.02)，逐通道 | 3.37 | 采用（P2 为整图 min(R,G,B) 的 2% 分位） |
| 同上，统计量换成亮度 0.5% 分位 | 3.38–4.4 | |
| 按整图平均亮度调 γ | 更差 | IMG_5770 从 2.6 恶化到 6–11 |
| 只改亮度（不逐通道） | 4.56 | 像素蛋糕确实提高了背景饱和度 |

两处修正：
- **软黑点**：`x' = (x − b·s(x))/(1 − b)`，s = smoothstep(0, 2b, x)。亮部同硬黑点、暗部不截断——硬黑点把
  1V3A3150 新郎的头发压成死黑，参考图上头发有层次；留一误差不变（3.65 / 3.66）。
- **只作用在保边底图上、细节原样加回**：逐像素拉伸把 1V3A3150 脸上的纹理放大 1/(1 − 0.31) ≈ 1.44 倍（低频能量比
  1.47），参考图上几乎不变（1.10）；改在底图上后为 1.12。

### 2.3 人物比同色背景亮
用"背景 LUT"预测人物的非皮肤像素（衣物、头发），6 张照片上人物都比同色背景亮 6～16 L（中间调最多），对应 AI 风格
里"主体"的提亮。建模为 Lab 中 `L += s(L)`（L = 0, 20, …, 100 处取值的分段线性曲线）与色度增益，按人像 alpha
（MODNet）混合。自适应黑点在人物上**同样生效**：只作用于背景时主体的留一误差 4.04，同样作用时 3.29
（1V3A3150 的婚纱与西装 8.4 → 2.2）。

人像 alpha 偶尔把背景里的一块当成人（1V3A3127 背景墙上的圆形灯饰，alpha ≈ 1）：主体提亮后成了一块亮斑。
`subject_weights` 在 1/16 瞳距尺度上把 alpha 二值化、做半径 0.05 瞳距的开运算，只保留含人脸中心或面积 ≥ 整图 1%
的四连通块，再羽化回原分辨率乘到 alpha 上——人与人相连的部分（婚纱、手臂）不受影响。

### 2.4 LUT 的尺寸与平滑
平滑 LUT（三线性，三个方向二阶差分正则、各照片等权）的留一误差（背景 / 主体）：

| 尺寸 / 平滑 | 背景 | 主体 |
|---|---|---|
| 33³ / 1e-4 | 5.84 | 3.20 |
| 33³ / 1e-3 | 5.04 | 3.18 |
| 25³ / 3e-4 | 4.78 | 3.10 |
| **17³ / 3e-3** | **3.65** | **3.30** |
| 13³ / 3e-3 | 3.56 | 3.33 |
| 9³ / 1e-3 | 3.50 | 3.18 |

大 LUT 会记住每张照片自己的颜色，泛化反而差；17³ 与更小的差别在 8 张样本的噪声内，取 17³（保留色相分辨率，
在这 8 张上的误差 0.6–1.7）。最终参数：`luts/wedding_dark_interior.cube`（编译进程序）、黑点 (P2, 0.6, 0.02)、
主体 `lightness = [1.45, 5.19, 6.53, 6.53, 5.67, 4.44]`、`chroma = 0.097`。

### 3.1 先调色、后修图

女 21.1 → 15.0），偏白的反而加暖（1V3A2922 女 4.7 → 11.3、1V3A2954 女 5.2 → 8.0），而同一张图的背景被压暗 10 L
以上——肤色统一作用在**调色之后**的颜色上，把皮肤拉回目标色。于是奶油肌模式下预设调色在修图之前作用于底图，
奶油肌的肤色常数在"只调色、不修图"的输出上重新拟合（`tools/skin_tone_fit.py`、`tools/body_tone_fit.py`）：

### 3.2 磨皮：对应"中性灰平整"，按带通的中位幅度校准
像素蛋糕这组的质感磨皮很轻（0.25），但中性灰"平整" 0.8——把 0.03～0.06 瞳距尺度上的明暗起伏压平。最初按
`tools/batch_compare.py` 的纹理 **RMS** 能量比校准，得到女 0.30 / 0.10、男 0.15 / 0.03（比奶油肌轻）；成片脸上留着
明暗斑块，男性尤其不够平滑。原因是 AI 风格的清晰度（全局 +4、主体 +7）与对比度（+10）放大了少数强边缘（毛孔、
皱纹、发丝），RMS 由这些强边缘主导，看起来"纹理没减少"；皮肤上大多数像素的起伏其实被压平了。改用皮肤亮度各带通
（σ = 0.004 / 0.008 / 0.016 / 0.032 / 0.064 瞳距，光流对齐到原图）的**中位幅度**相对原图之比

−0.07 → −0.02；立体抬高的斑驳一档由 low_smooth 0.50 压回。

### 3.3 身体皮肤的黄色色块：肤色外溢
1V3A3101、3127 新娘贴着红礼服的胸口下部被语义皮肤模型判成非皮肤（礼服的红色反光），这片皮肤不做身体色调；
该预设的身体色调很强（提亮 6.8、黄度按 0.67 拉向 10.1，奶油肌为 4.6 / 0.19），漏掉的一片与处理过的皮肤差出一块
黄色（调色后 b 24 → 处理过的皮肤 14.5，漏掉的仍是 19～24；参考 12）。奶油肌同样漏检，只是色调轻、看不出。

`skin::spill`：遮罩外、人像内、离脸远、离已接受皮肤 0.3 瞳距以内、低频颜色与附近已接受皮肤相近的像素按相似度
并入身体色调与混合遮罩（磨皮、祛瑕疵仍只在遮罩内）。两处细化：
- 贴着红礼服的一条被映红（a 高 5～6、黄度不降，色相 47°～52°），按 Lab 距离差 5～6 只得部分权重，留下一道橙边。
  比参考更红、且本身是肤色色相（≥ 35°）时红度差折半；1V3A2954 的粉玫瑰、IMG_5785 的扇骨同样比皮肤红 6，但色相
  15°～18°，不折（只按"黄度不降"区分时玫瑰仍被改动，ΔE 最大 7.6）。
- 区域生长：确认的外溢皮肤（权重 ≥ 0.5、肤色色相）加入参考色再算两轮，参考色跟着连续的皮肤渐变走；外溢范围
  仍由原始遮罩的邻近度限定。渐变的高光在单轮时权重 0.02、细化后 0.83，同样颜色的突变仍为 0。

1V3A3101 胸口贴裙的一条（x 2840～2880）b：修改前 17～23 → 14.6～16.4，参考 12～12.7。

### 3.4 脸上的色块：脸部遮罩越界
IMG_5785 新娘右颊外侧一块偏米黄、边界分明，右眼睫毛发金。原因不在磨皮或肤色模型：新郎（脸 0）的人脸解析
裁剪框包含新娘的半边脸，解析把她的右颊、右眼周围也标成"皮肤"，于是那片先按男性参数（黄度拉向 18.3、红度拉向
6.8，女性为 13.2 / 4.8）处理一遍，再按女性参数处理；睫毛只在新郎的遮罩里，被当成皮肤提亮、拉黄。反过来新娘的
遮罩盖住新郎左半边脸，在她的解析框边上竖直切断，新郎脸上一条接缝。批量测试的贴脸 / 亲吻照（1V3A2837、3188、
3194）越界更严重，有的整张脸都在对方的遮罩里。

修正：每张脸的遮罩去掉落在别人脸轮廓内、又不在自己轮廓内的部分（轮廓 = 关键点下颌线 + 额头点围成的多边形，
1/k 分辨率上羽化 0.04 瞳距）；轮廓都不覆盖的耳朵、发际、羽化边照常。按"到脸中心的距离 / 脸尺度"分配不可靠：
3188 新郎的脸比新娘大得多，被吻的额头按尺度算离新郎更近，会削弱她自己的处理。5785 新娘在 0.032 瞳距一档的
带通比 0.86 → 0.80（参考 0.80）。奶油肌同样越界，男女参数差得小、看不出，不开（输出不变）。

### 3.5 牙齿美白
像素蛋糕开了牙齿美白 0.3 与牙齿祛瑕疵 0.75。露齿的只有 1V3A3101、1V3A2954 两位新娘；对调色后（未美白）的图
光流对齐、逐像素比较：黄度 b 27.6 → 10.8、红度 a 18.2 → 10.1（本来不黄的 b 7.9 不动），亮度 +3～+9、越暗提得
越多（≈ 0.15 ×（100 − L）），亮度起伏不变；紧挨牙齿、被牙龈与唇色映红的一圈（a 28～40）也减红减黄约一半，嘴唇
（a ≥ 40）基本不动。

`skin::teeth`：人脸解析的口腔（`CLS_MOUTH`）内，亮度门限（L 35→50）× 相对红度门限——参考红度取口腔最亮 25% 像素
的中位数（暖色内景、红裙映在牙齿上时门限跟着移；固定门限漏掉靠近牙龈、被映红的上半截牙齿）；红度、黄度拉向
a 10、b 10，亮度向 100 拉 18%；牙齿权重羽化后乘 2 覆盖牙龈线（嘴唇更红、不动）。门限取调色后、修图前的颜色，

## 4. 实现

| 环节 | 实现 | 位置 |
|---|---|---|
| 预设调色 | 软黑点（保边底图上）→ 全局 3D LUT → 人物主体 LUT（按人像 alpha 混合） | `color/grade.rs` |
| 顺序 | 奶油肌：AI 瑕疵补丁 → 预设调色 → 修图 → 形变；其余磨皮模式在磨皮之后调色 | `pipeline.rs` |
| 人像 alpha | 预设调色需要主体调整时也计算（原来只在处理身体皮肤时） | `engine.rs` |
| 预设 | `Preset::wedding_dark_interior`（别名 `婚纱-深色内景` / `wedding_dark` / `dark_interior`），`grade` 字段 | `preset.rs`、`presets/wedding_dark_interior.json` |
| 主体权重 | 人像 alpha 去掉与人脸不相连的小块 | `color/grade.rs`（`subject_weights`） |
| 肤色外溢 | 漏检的相邻皮肤并入身体色调（映红折让、参考色细化） | `skin/spill.rs`，`CreamParams::body_tone_spill` |
| 牙齿美白 | 口腔解析 × 自适应颜色门限，拉向暖白、提亮 | `skin/teeth.rs`，`CreamParams::teeth_whiten` |
| 脸部遮罩归属 | 去掉落在别人脸轮廓内的解析遮罩 | `skin/cream.rs`（`FaceOutlines`），`CreamParams::face_ownership` |
| 立体 | 脸内 0.06–0.25 瞳距的明暗结构按比例加强 | `skin/cream.rs`（第 5b 步），`CreamParams::stereo` |
| 拟合 | LUT、黑点、主体曲线 | `tools/grade_fit.py` |

## 5. 局限
- 像素蛋糕的自适应规则未知，自适应黑点是近似：留一误差背景 3.7、主体 3.3（固定 LUT 为 5.7），1V3A2922 与
  1V3A3150 仍在 5 左右；样本只有 8 张、多为户外，真正的深色室内场景没有参考。
- 肤色的比例模型是跨脸的折中：1V3A2922 的皮肤在调色后偏蓝，拉回后仍比参考少黄约 3.5。
- 肤色外溢靠颜色与邻近度：1V3A3127 胸口上沿一片高光（比肩颈的已接受皮肤亮 8、红度与黄度各低 6）仍未处理，
  b 20 对参考 12；再放宽会把贴着皮肤的象牙色 / 香槟色婚纱当成皮肤，没有放宽。
- 肤色是跨脸拟合的比例模型：IMG_5785 新娘比参考黄约 1.7、腮红更淡（女性 6 张脸平均反而少黄 0.4），像素蛋糕的
  "AI 肤色统一"逐脸自适应，未复现。
- 祛双下巴、祛眼周纹、祛碎发、牙齿祛瑕疵 / 排齐、唇纹、头发柔顺、小腿、AI 面部流畅等不模拟。
